# Contributing

Contributions should help a learner understand, apply and verify one concept. Start with [the lesson template](templates/LESSON-TEMPLATE.md) and the [maintainer standards](docs/MAINTAINERS.md).

## Useful contributions

- Clarify a confusing explanation or add a worked trace.
- Add boundary cases or a regression for an incorrect result.
- Extend a practice series with a precise specification and separate solution.
- Add an advanced-roadmap topic as a complete lesson rather than an empty folder.
- Improve accessibility, navigation or a translation while preserving technical meaning.

## Before submitting

1. Work on a branch and keep the change focused.
2. Include prerequisites, expected outputs and invalid-input behavior.
3. Use descriptive names and document units and caller permissions.
4. Run npm ci followed by npm run check.
5. Describe the learner-facing change and the validation performed.

Use the issue template for an explanation/code mismatch. For security-sensitive production findings, follow the affected project's own reporting process; these teaching contracts are not deployed services.

Keep original notices and attribution. Contributions to this course are under the repository's MIT license. Do not include secrets, real private records or copyrighted course material you do not have permission to share.
