# Module 13 — Three exercises

Complete these without opening Solutions.sol. Write a prediction, test a normal and a boundary case, and inspect a revert whenever relevant.

### Warm-up
Create an interface to a public count() getter and read it from a separate contract.

### Application
Build a library for checking if an integer is even; call it using a using-for declaration.

### Challenge
Explain why an address cast to an interface cannot establish that a target is reliable.

For each task document contract inputs, expected values, actual values, and why you believe the result is correct.
