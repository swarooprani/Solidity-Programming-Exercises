# Module 13 — Answers and reasoning

### 1. What is an interface?

**Answer:** A contract API declaration without method bodies.

### 2. What is a library useful for?

**Answer:** Reusable functions that reduce duplication.

### 3. What does using-for enable?

**Answer:** Extension-method syntax on compatible values.

### 4. Does an interface cast prove target trust?

**Answer:** No.

### 5. What is composition?

**Answer:** Building features by interacting with independent components rather than only inheriting.
