# Module 11 — Three exercises

Complete these without opening Solutions.sol. Write a prediction, test a normal and a boundary case, and inspect a revert whenever relevant.

### Warm-up
Add a restock function rejecting zero quantities, with a Restocked event.

### Application
Create an owner-restricted update that emits a log only on success.

### Challenge
Explain how assert differs from require and why a reverted event cannot be used by an indexer as successful history.

For each task document contract inputs, expected values, actual values, and why you believe the result is correct.
