# Module 12 — Three exercises

Complete these without opening Solutions.sol. Write a prediction, test a normal and a boundary case, and inspect a revert whenever relevant.

### Warm-up
Create an abstract Pricing contract with a virtual price(uint256) method.

### Application
Implement two derived contracts for different pricing strategies and compare results on the same input.

### Challenge
Override a base label method and use super to call inherited behavior from the derived contract.

For each task document contract inputs, expected values, actual values, and why you believe the result is correct.
