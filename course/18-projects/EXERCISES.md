# Module 18 — Practice

**Directions:** implement your own file in Remix. Predict three normal or boundary outputs and test an invalid input when applicable. Avoid looking at the reference until finished.

### Exercise A — Warm-up
Capstone A: implement a multi-student gradebook with score limits, a teacher-only setter, and missing-record detection.

### Exercise B — Application
Capstone B: implement inventory keyed by product ID, with adding stock and rejecting invalid sales.

### Exercise C — Challenge
Capstone C: extend the original event registration program with cancellation and test duplicate registration, capacity limits, and invariant preservation.

## Self-evaluation
Check the type of each input, who may call the function, and how storage changes. A reverted transaction must not leave partial changes. Write one paragraph about a mistake you corrected.
