# Module 10 — Three exercises

Complete these without opening Solutions.sol. Write a prediction, test a normal and a boundary case, and inspect a revert whenever relevant.

### Warm-up
Create an owner-controlled counter with an unrestricted increment and owner-only reset.

### Application
Test the protected method from two separate Remix VM accounts and explain why the failed call does not modify state.

### Challenge
Implement a two-step ownership transfer using pendingOwner; prevent zero-address proposals and let only the pending owner accept.

For each task document contract inputs, expected values, actual values, and why you believe the result is correct.
