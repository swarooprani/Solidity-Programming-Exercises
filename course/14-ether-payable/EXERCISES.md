# Module 14 — Three exercises

Complete these without opening Solutions.sol. Write a prediction, test a normal and a boundary case, and inspect a revert whenever relevant.

### Warm-up
Write a payable donation function that emits a Donation event with the amount.

### Application
Add a withdrawAll function to a credited vault and explain the checks-effects-interactions order.

### Challenge
Discuss why total Ether balance and a credited deposit mapping need not always be identical.

For each task document contract inputs, expected values, actual values, and why you believe the result is correct.
