# Module 06 — Answers with explanations

### 1. What is the first array index?

**Answer:** 0.

### 2. Can you push onto a fixed-length array?

**Answer:** No; its size is fixed.

### 3. What does `.pop()` do on a dynamic storage array?

**Answer:** Removes its last element (reverting if the array is empty).

### 4. What happens on an out-of-bounds array read?

**Answer:** The call reverts.

### 5. Is UTF-8 byte length always the number of letters?

**Answer:** No. Some characters require multiple bytes.
