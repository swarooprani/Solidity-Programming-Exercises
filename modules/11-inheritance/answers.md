# Quiz answers

**1. Does inheriting a base deploy a separate parent instance?**

No. The derived instance includes inherited behavior and state.

**2. Which keyword permits a base function to be overridden?**

virtual.

**3. Which keyword marks a replacing derived implementation?**

override.

**4. Can an abstract contract be deployed directly?**

No. Deploy a concrete contract implementing its missing functions.
