# Exercises

Implement these in a separate practice file. Work in order: warm-up, application, challenge. Use the exact behavior below; function names match the reference solutions.

## 05.1: Count even numbers — Warm-up

Implement countEven(a), allowing at most 100 uint256 items. Count zeros as even. [] → 0; [0,1,2,4] → 3. Reject 101 items.

Record your expected outputs before running. Check the normal result, a boundary case and the specified failure behavior.

## 05.2: Search with an explicit result — Application

Implement find(a,target) returning (found,index), with at most 100 items. [8,4,8],8 → (true,0); missing → (false,0). Return the first match; distinguish missing from index zero.

Record your expected outputs before running. Check the normal result, a boundary case and the specified failure behavior.

## 05.3: Reverse a copy — Challenge

Implement reverse(a) returning a new memory array, with at most 100 items. [1,2,3] → [3,2,1]; [] → []. Leave the input unchanged.

Record your expected outputs before running. Check the normal result, a boundary case and the specified failure behavior.
