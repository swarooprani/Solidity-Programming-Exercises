# Quiz answers

**1. Which loop always executes its body at least once?**

do-while. Its condition is checked after the body.

**2. Does continue skip the update expression in a for loop?**

No. It proceeds to the update and then checks the condition.

**3. Does break exit all nested loops?**

No. It exits only the nearest enclosing loop.

**4. Will while(true) wait for a user to change storage?**

No. It executes within the current call until an exit or failure, typically out of gas.
