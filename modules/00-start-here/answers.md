# Quiz answers

**1. Does compiling a file create a deployed instance?**

No. Deployment is a separate action that creates an instance at an address.

**2. Do two deployments share the same number variable?**

No. Each instance has independent storage.

**3. Does a contract automatically run every minute?**

No. A call must trigger execution; an external automation service can submit calls.

**4. Does pragma select the compiler for you?**

No. It checks whether the compiler you selected is compatible.
