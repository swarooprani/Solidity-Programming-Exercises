# Quiz answers

**1. What are the valid indexes of a length-3 array?**

0, 1 and 2.

**2. Does delete items[1] shorten a uint256 array?**

No. It writes zero at that index and preserves length.

**3. Does bytes(text).length always count characters?**

No. It counts bytes; UTF-8 characters can use several bytes.

**4. Can a dynamic memory array use push?**

No. Its allocated length is fixed for that allocation.
